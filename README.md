# Curso ADVPL 2.0

Repositório criado para armazenar e organizar os materiais de estudo do curso Consultor Protheus 2.0, voltado ao desenvolvimento em ADVPL e TL++ no ERP TOTVS Protheus.

## Conteúdo

O repositório contém 37 pastas organizadas por módulos, incluindo:

- Videoaulas;
- Códigos-fonte ADVPL e TL++;
- Exercícios e projetos práticos;
- Arquivos compactados (.zip e .rar);
- Ferramentas e materiais complementares.

## Tópicos abordados

- Elementos visuais ADVPL e TL++;
- Desenvolvimento de sistemas;
- Pontos de entrada no Protheus;
- Arquitetura MVC e validações;
- JOBs no Protheus;
- Web Services e integrações;
- APIs REST;
- Business Intelligence;
- Microsoft Power BI;
- Configuração e desenvolvimento no Visual Studio Code.

## Tecnologias e ferramentas

- TOTVS Protheus;
- ADVPL;
- TL++;
- Visual Studio Code;
- Git e GitHub;
- Git LFS;
- Postman;
- SoapUI;
- Power BI.

## Armazenamento

Os arquivos de vídeo são gerenciados pelo Git LFS (Large File Storage), conforme as configurações definidas no arquivo `.gitattributes`.

## Objetivo

Centralizar os materiais do curso, preservar os arquivos e facilitar o acesso para estudos, consultas e desenvolvimento em diferentes computadores.

## Direitos autorais

Os materiais pertencem aos seus respectivos autores e são destinados ao estudo pessoal, respeitando os direitos autorais e as condições de licenciamento do curso.
